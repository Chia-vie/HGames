# HGames

## Preamble

Small games coded by participants of the Hernstein Python Camp.
Import the different modules to test out our mini-games and make your projects more fun.
Use all our games, from Tic Tac Toe to an encrypter, for your projects. Have fun!

## How to run files

First, download the Python interpreter. Next, run this exact command to install
all dependencies:

`pip install -r requirements.txt`

Now, you can use the classes provided to create your own software.
